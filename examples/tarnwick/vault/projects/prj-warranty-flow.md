# Warranty claims flow

## Summary
Dealers file warranty claims on a web form instead of by e-mail. A claim for a cracked frame
within the five-year frame warranty goes straight to [[per-kofi-mensah|quality]] with photos.

## Status
Live for dealers in the UK and Germany since April 2026. Average time to a decision fell from
nine days to four.
